# Accessibility Statement for SpectraNetworkManager

Biohazard Corp and the SpectraNetworkManager team are committed to ensuring digital accessibility for people of all abilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

---

## Measures to Support Accessibility

SpectraNetworkManager incorporates the following accessibility features:

1. **Theme & Contrast Modes:**
   - Both Dark Mode (default neon/cyber aesthetic) and Light Mode (clean, high-contrast palette) are supported.
   - Text elements and borders maintain high contrast ratios against background panels.

2. **Keyboard Navigation:**
   - All interactive controls, buttons, text fields, and tabs can be reached and activated using the keyboard (`Tab`, `Shift+Tab`, `Enter`, `Space`, and Arrow keys).
   - Fast keyboard shortcuts are available for primary navigation and critical actions.

3. **Screen Reader Compatibility:**
   - WPF UI elements include accessible naming and structure compatible with Windows Narrator, NVDA, and JAWS.
   - Live network grid views and DNS logs provide structured headers and column descriptions.

4. **Visual Indicators:**
   - Important statuses (Allowed, Blocked, Untrusted Signatures) use both color differentiation and distinct textual / icon badges so information is not conveyed by color alone.
